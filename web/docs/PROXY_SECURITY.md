# 模型代理安全边界

## 允许的网络能力

本站代理只用于现有模型预设的模型列表和聊天补全请求。服务器校验精确的 HTTPS origin、base path、API path 与方法，不接受任意用户地址；拒绝 URL 用户信息、查询参数、fragment、非默认端口和 IP 地址目标。

对允许的主机，服务器解析 DNS 并拒绝任意非公网结果，将已验证地址固定到 HTTPS 连接。TLS 证书和 SNI 仍按原始主机校验。连接不跟随重定向，避免跳到未批准目标或在跳转中发送 Key。

请求体上限 256 KiB，响应体上限 2 MiB；只接受 JSON，不支持流式请求；DNS、连接和读取受 120 秒总超时控制。上游响应头和内部错误不直接暴露给客户端。响应禁止缓存。

## 滥用防护

- 移除任意来源 CORS，拒绝浏览器跨站请求。
- 要求模型 Bearer Key；它用于上游模型认证，不是本站用户身份。
- 生产环境必须使用共享 Redis 的原子全局/客户端限流，当前上限为全站每分钟 30 次、客户端每分钟 6 次；缺配置或服务失效时拒绝上游调用。Vercel 上仅信任平台覆盖的客户端 IP 头，其他环境将客户端归入统一桶。
- 仅本地开发使用有界进程内限流；在多个 Vercel 实例间不能依靠内存计数。
- 前端不会在代理拒绝、限流或网络异常后自动改为浏览器直连。

Origin 检查和模型 Key 都不能阻止程序伪造客户端请求；公共服务的注册登录、账号额度和平台防火墙仍是后续必要的独立控制。共享限流减少允许的模型 API 的资源滥用，不能保证消除所有网络攻击或无限重试成本。

## 注册内测的后续约束

计划采用网站统一模型、最多 100 个有效账号、每人每天 5 次成功的大纲生成。改造应使用服务端固定模型地址和 Key，移除用户可控的 URL、Key 及模型选择；只接收 PPT 生成参数。

名额、每日额度和任务预占需要数据库原子事务；同一任务使用幂等标识，账号同时最多一个任务。仅在服务端确认失败时退额度，浏览器声称导出失败不能触发免费重生成。成功大纲可以重新下载而不再次调用模型。

登录验证、邀请码/邮箱验证、每日尝试上限、并发上限与全站费用熔断共同控制滥用。每日重置以 Asia/Shanghai 的日期为准。认证或额度数据库失效时不调用付费模型。

本补丁尚未实现上述账号系统，也没有将每日计数器当作用户认证。

## 验证

在 `web/` 执行 `npm test` 和 `npm run build`。安全回归使用模拟 DNS、HTTPS 和 Redis，验证允许请求与危险目标、私有 DNS、重定向、大小/超时、限流服务失效等拒绝路径；不对云元数据或任何敏感内网服务发探测请求。

设计参考：[OWASP SSRF Prevention Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Server_Side_Request_Forgery_Prevention_Cheat_Sheet.html)。
