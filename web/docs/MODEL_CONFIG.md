# 网站模型配置准备

网站选定的模型是 `MiniCPM-V-4.7-1B`，固定 Base URL 为 `https://api.modelbest.cn/v1`。前端默认值和 ModelBest 预设已更新；请求显式使用 `stream: false` 与 `max_tokens: 6000`。浏览器已经保存的用户模型配置仍会被保留。

1B 使用简短提示词，仅填写扁平的 `title` 和每页 `page_N_title` / `page_N_body`。程序逐字段校验后按固定页数组装封面、内容及结尾页；模型不负责生成版式类型或嵌套结构。其他模型保留完整设计系统提示词。返回大纲必须满足请求页数、首封面、末结尾及可用页面结构；校验失败直接提示，不截断内容、不补造页面、不自动重新调用模型。

实测 1B 偶尔会在完整 JSON 对象末尾多写右括号。仅对 1B 允许本地移除最多三个多余右括号，扫描时识别字符串、转义及嵌套；任何额外正文、第二对象、数组碎片或缺失闭合都拒绝。这不新增模型调用，修复后仍执行所有字段和页数校验。

`src/lib/server/model-config.ts` 是后续统一模型接口的配置准备模块，使用 `server-only` 防止客户端导入。它只读取服务端环境变量 `MODELBEST_API_KEY`，不从环境变量或客户端参数读取模型名、Base URL，也不会自行发送网络请求。缺失或非法 Key 只产生固定错误，不回显凭证。配置对象包含 Key，仅供服务器内部调用，不能序列化到页面或接口响应。

**统一网站 Key 暂未启用。** 当前公开 `/api/proxy` 仍使用用户自行填写的 Key，且不导入这个配置模块。网站注册、邮箱认证、100 名额及每日额度还未完成；不能因为服务器已经保存 Key，就让匿名接口使用它。

后续统一模型接口只有在服务端真实身份认证、Postgres 原子额度预占与幂等任务、账号和全站并发限制、每日尝试次数及费用上限全部接入后，才能调用这个模块。统一 Key 应放在平台 Secret 或被 Git 忽略的 `.env.local`，禁止放入前端、`NEXT_PUBLIC_*`、源码、日志或响应。

当前 `max_tokens: 6000` 是浏览器请求的显式参数；公共 BYOK 代理仍不是网站统一模型的计费或额度执行器。未来使用网站 Key 的接口必须在服务器强制设置模型和输出上限，忽略客户端提供的对应参数。
